This is a semester project for the World Wide Web course at the University of Pardubice. The goal is to create a modern, responsive, and high-quality static frontend for the University Football League (UFoL), built from scratch without CSS frameworks to gain a thorough understanding of fundamental web technologies.

---

## 🚀 Live Demo

**[Link to live demo here](https://matous-ben.github.io/ufol-frontend-project/)**

---

## 🎯 Project Goals and Requirements

This is a static web presentation designed to meet the following requirements:
* **4 unique layouts:** Homepage, Table, Matches, Teams.
* **High graphic standard:** Design created in Figma.
* **Semantic HTML5:** Clean and logical document structure.
* **Responsive design:** Responsive behavior across different devices with 3 breakpoints.
* **No CSS frameworks:** All styles are written in custom, modern CSS (Flexbox, Grid, CSS variables).
* **Valid code:** Code validated using W3C validator.

---

## 🛠️ Technologies Used

* **HTML5** (Semantic structure)
* **CSS3** (Responsive layout using Flexbox & Grid, CSS variables)
* **Figma** (For design and all layouts)
* **GitHub & GitHub Pages** (For versioning and deployment)

## 🎯 Cíle projektu a zadání

Toto je statická webová prezentace navržená tak, aby splnila následující požadavky:
* **4 unikátní layouty:** Homepage, Tabulka, Zápasy, Týmy.
* **Vysoký grafický standard:** Design vytvořený ve Figmě.
* **Sémantické HTML5:** Čistá a logická struktura dokumentu.
* **Responzivní design:** Responzivní chování na různých zařízeních se 3 breakpointy.
* **Žádné CSS frameworky:** Všechny styly jsou psány ve vlastním, moderním CSS (Flexbox, Grid, CSS proměnné).
* **Validní kód:** Kód validovaný pomocí W3C validátoru.
